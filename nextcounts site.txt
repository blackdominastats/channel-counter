Authenticate with your API key
Create a named key in API keys and send it in the X-API-Key header. Keep it on your server; never include it in a shared URL.

Quota and caching
Rate limits are deployment-configured. Read X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset and Retry-After. Dashboard keys also expose X-NC-Quota-Limit, X-NC-Quota-Remaining and X-NC-Quota-Reset. All keys belonging to one account share a daily UTC quota: 20,000 for standard accounts and 1,000,000 for Studio and NCPro. Renaming, rotating or replacing a key does not reset usage.

Your website access stays available.
Running out of developer quota does not block ordinary NextCounts website access or dashboard management. Custom live counters use their creator’s quota, including when viewed privately on NextCounts or through a shared link. External viewers are never charged.

Counter refreshes run only while viewed and may return cached platform data. They pause when the creator’s quota is exhausted. A slower refresh interval reduces consumption.

Observation time matters
When present, observedAt is Unix milliseconds. X-NC-Cache, X-NC-Data-Age and X-NC-Max-Age describe the cached observation, not a promise of a new platform fetch. Missing counts remain null. Public responses use opaque seriesId values; do not infer a collection source from them.

Errors and retries
Check the HTTP status and, for public data responses, success. Use the error code for application behavior and keep the trace ID for support.

{
  "success": false,
  "error": {
    "code": "Stable machine-readable code",
    "message": "Public message",
    "traceId": "Support reference",
    "details": "Optional validation or operational details"
  }
}
400
NC-INPUT-400
Invalid identifier, query or unsupported capability. Correct the request.
401 / 403
NC-AUTH-401 / NC-AUTH-403
Authentication or publication access is unavailable. Do not continuously retry.
404
NC-RES-404 or platform-specific code
Unknown or unavailable resource. Check the platform capability and stable identifier.
Eligibility
NC-ANALYTICS-MINIMUM
History tracking is not available for this resource yet; live data may still work.
429
NC-RATE-429
Rate limit reached. Respect Retry-After and apply backoff.
401
INVALID_API_KEY
A dashboard-issued key is invalid, rotated or revoked. It does not fall back to anonymous access.
429
DASHBOARD_QUOTA_EXCEEDED
The shared UTC developer allowance is exhausted. Named-key requests and custom counter refreshes share it. Ordinary website access and dashboard management remain available. Private and shared custom counters consume their creator’s quota; viewers are never charged. Wait until reset for further quota-backed requests.
500 / 502 / 503 / 504
NC-SYS-500 or operational code
Temporary service failure. Retry with bounded backoff and retain the traceId for support.
Use bounded retries with backoff for temporary failures. Cache reads and pause polling when a view is hidden. A realtime route name does not imply an uncached request.
